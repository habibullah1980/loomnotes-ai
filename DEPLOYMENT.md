# LoomNotes AI — Vercel & Supabase Production Deployment Guide

This guide provides a step-by-step walkthrough to deploy **LoomNotes AI** to **Vercel** with a production **Supabase** backend.

---

## Step 1: Push Project to GitHub

1. Initialize git repository (if not already done) and commit the latest code:
   ```bash
   git init
   git add .
   git commit -m "feat: prepare LoomNotes AI for production Vercel launch"
   ```
2. Create a new private or public repository on GitHub (e.g. `your-username/loomnotes-ai`).
3. Add the remote and push your main branch:
   ```bash
   git branch -M main
   git remote add origin https://github.com/your-username/loomnotes-ai.git
   git push -u origin main
   ```

---

## Step 2: Import Repository into Vercel

1. Log into your [Vercel Dashboard](https://vercel.com/dashboard).
2. Click **Add New...** → **Project**.
3. Under **Import Git Repository**, select your `loomnotes-ai` repository and click **Import**.
4. Configure the Project Settings:
   - **Framework Preset**: `Next.js`
   - **Root Directory**: `./` (leave default)
   - **Build Command**: `npm run build`
   - **Output Directory**: `.next`
   - **Install Command**: `npm install`

---

## Step 3: Add Environment Variables in Vercel

Under the **Environment Variables** section in Vercel, add the following variables for **Production**, **Preview**, and **Development**:

### 3.1 Public Variables (Client Accessible)
- `NEXT_PUBLIC_APP_URL`
  - Production: `https://your-domain.vercel.app` (or your custom domain `https://loomnotes.ai`)
- `NEXT_PUBLIC_SUPABASE_URL`
  - Your production Supabase project URL (e.g. `https://xyzcompany.supabase.co`)
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
  - Your production Supabase anonymous public key (`eyJ...`)

### 3.2 Server-Only Secrets (Isolated to Server Runtime)
- `SUPABASE_SERVICE_ROLE_KEY`
  - Your production Supabase service role secret key (`eyJ...`)
- `GEMINI_API_KEY`
  - Your Google AI Studio API key (from https://aistudio.google.com/)
- `GEMINI_MODEL`
  - `gemini-2.5-flash` or `gemini-3.5-flash-lite`

> 🔒 **Security Notice**: Never prefix server secrets with `NEXT_PUBLIC_`. Secrets are automatically protected from client bundle inclusion.

---

## Step 4: Configure Supabase Production Settings

In the **Supabase Dashboard** for your production project:

### 4.1 Authentication & URL Configuration
Navigate to **Authentication → URL Configuration**:
1. **Site URL**: Set to your canonical production URL (e.g., `https://your-domain.vercel.app` or `https://loomnotes.ai`).
2. **Redirect URLs**: Add the following callback patterns:
   - `https://your-domain.vercel.app/**`
   - `https://your-domain.vercel.app/auth/callback`
   - `https://your-domain.vercel.app/reset-password`
   - `https://*.vercel.app/**` (allows preview branch deployments)
   - `http://localhost:3000/**` (allows local development)

### 4.2 Email Authentication
Navigate to **Authentication → Providers → Email**:
- Enable **Email provider**
- Ensure **Confirm email** is set according to your user onboarding preference
- Configure SMTP settings (optional, for custom domain email delivery)

### 4.3 Database Tables & RLS Verification
Ensure the following tables are present with active Row-Level Security (RLS) policies:
- `profiles`
- `meetings`
- `action_items`
- `key_takeaways`
- `key_decisions`
- `follow_up_questions`
- `usage_tracking`
- `admin_audit_logs`
- `activity_events`

---

## Step 5: Deploy & Verify

1. In Vercel, click **Deploy**.
2. Wait for the build process to complete (Next.js 16.3.8 Turbopack will compile all 28 static and dynamic routes).
3. Once deployed, open your live application URL and perform a quick smoke test:
   - Sign up a new user account with email/password.
   - Access the `/dashboard`.
   - Create a new meeting from a transcript or Loom share link.
   - Verify the 5-section AI notes generated by Google Gemini.
   - Check and toggle an action item.
   - Test password reset on `/forgot-password`.
   - Access the Super Admin console at `/admin` (if using an authorized admin account).

---

## Custom Domain Setup (Optional)

1. Navigate to **Project Settings → Domains** in Vercel.
2. Enter your custom domain (e.g., `loomnotes.ai`).
3. Configure your DNS records at your registrar:
   - **Type A**: `@` → `76.76.21.21`
   - **Type CNAME**: `www` → `cname.vercel-dns.com`
4. Update `NEXT_PUBLIC_APP_URL` in Vercel Environment Variables to your custom domain.
